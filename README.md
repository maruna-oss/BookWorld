# BookWorld — Електронний каталог книг

Навчальний консольний застосунок, розроблений мовою програмування C++.

## Команда розробників
- Команда: Read&Create
- Учасниці: Марина та Ангеліна

## Опис та мета проєкту
BookWorld — це електронний каталог книг, створений для зручного зберігання інформації про літературні твори у текстовому файлі та їх швидкого перегляду через консольне меню.
Мета проєкту: опанувати повний цикл командної розробки програмного забезпечення — від проєктування модульної архітектури та написання коду мовою C++ до автоматизованого тестування, виправлення дефектів і документування.

## Основні реалізовані можливості
- **Завантаження каталогу з файлу (Catalog::loadFromFile):** зчитування записів із текстового файлу data/books.txt (роздільник полів |).
- **Перегляд списку книг (Catalog::showAllBooks):** зручне та структуроване виведення назви, автора, жанру та опису кожної книги українською мовою (UTF-8).
- Обробка помилок вводу та пошкоджених даних:
  - захист головного меню від нечислових символів (літер або спецсимволів) без зациклення;
  - фільтрація пошкоджених рядків без обов'язкової назви книги;
  - підстановка тексту Не вказано, якщо у книги відсутній жанр або опис.
- **Автоматизоване тестування (tests/test_catalog.cpp):** 5 модульних тестів на базі <cassert>, які перевіряють 
позитивні та негативні сценарії роботи каталогу.

## Використовувані технології
- Мова програмування: C++ (стандарт C++17)
- Бібліотеки: стандартна бібліотека C++ (<iostream>, <fstream>, <sstream>, <vector>, <string>, <cassert>) та <windows.h> (для підтримки кирилиці UTF-8 у консолі)
- Компілятор та середовище: MSVC (cl.exe) / Visual Studio 2022–2026






- Контроль версій: Git та GitHub

## Вимоги для запуску
- Операційна система Windows 10 / 11.
-


 Компілятор C++ з підтримкою стандарту C++11 або новішого (наприклад, Microsoft Visual Studio з компонентом «Розробка класичних застосунків на C++»).

## Інструкція зі встановлення та запуску



1. Клонуйте репозиторій на свій комп'ютер:
  
   git clone https://github.com
 


  cd BookWorld
   
2. Відкрийте Developer PowerShell for VS у кореневій папці проєкту BookWorld.



3. Скомпілюйте та запустіть основну програму:
  
 

  cl /EHsc /utf-8 src\main.cpp src\Catalog.cpp /Fe:bookworld.exe
   .\bookworld.exe
   



4. Для запуску автоматизованих тестів виконайте:
  
 

  cl /EHsc /utf-8 tests\test_catalog.cpp src\Catalog.cpp /Fe:run_tests.exe
   .\run_tests.exe
